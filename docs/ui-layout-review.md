# UI 정렬 점검

2026-09-07, 1.2.1 소스 기준. 실제 AppKit 화면을 예제 상태로 오프스크린 렌더링했다. 창을 표시하거나 설정을 적용하지 않았다.

## 확인한 화면

| 경로 | 포함한 구성 | 확인 방식 |
| --- | --- | --- |
| 설치 | 기본, 브라우저/런처, 개발/AI, 편집기, 커뮤니케이션, 유틸리티의 17개 행 | 공통 행 소스와 한/영 렌더 |
| 텍스트/키보드 | 입력기, 전환, 반복, 기능 키, 교정 등 12개 행 | 공통 행 소스와 한/영 렌더 |
| 데스크톱 | 클릭, 배경화면, 두 핫 코너의 4개 행 | 한/영 렌더 |

| 시스템 확인창 | Setup 제거, 구름 적용 전 로그아웃 확인 | 소스만 확인; 실행하지 않음 |

## 수정과 측정 결과

- Dock 문서의 초기 고정 너비 때문에 최소 창 너비가 다른 탭보다 12pt 커지던 문제를 수정했다. 큰 최소 스크롤 높이도 줄여 탭 변경 시 창이 늘어나지 않게 했다.
- Dock 본문의 위 여백을 다른 탭과 같은 10pt로 맞췄다. 공통 행은 상태 열 142pt, 동작 영역 228pt, 버튼 110pt로 고정했다. Flow의 기본 동작도 다른 행처럼 오른쪽에 둔다.
- 간편 설정의 단계별 400/520/590/650pt 자동 높이 변경을 제거했다. 모든 단계는 같은 최소 높이 650pt에서 제목과 아래 버튼 위치를 유지한다.
- 단계 표시줄 높이와 체크 아이콘 자리를 고정했다. 완료 여부가 바뀌어도 제목이 이동하지 않는다. 단계 카드 제목은 왼쪽 정렬한다.
- 긴 의존성 안내는 행 너비 안에 머무르며 전체 문구를 툴팁으로 제공한다.

좌표는 창 콘텐츠 왼쪽 위 기준 pt다. 아래 값은 한국어와 영어의 모든 같은 단계 화면에서 일치했다. [전체 측정값](ui-layout-coordinates.json)

| 공통 요소 | x | y |
| --- | ---: | ---: |
| 기본 창 제목 / 탭 / 본문 / 하단 | 18 | 18 / 94 / 134 / 618 |
| 기본 행 상태 열 | 389 | 행마다 다름 |
| 간편 설정 제목 / 탭 / 단계 카드 | 24 | 24 / 66 / 106 |
| 간편 설정 단계 제목 / 설명 | 41 | 123 / 148 |
| 간편 설정 기본 버튼 | 526 | 598 |

기본 창 820×660, 간편 설정 720×650의 20개 화면에서 측정했다. 설치의 섹션 제목, Dock의 선택 목록 등 서로 다른 내용 구성은 유지한다. 공통 본문 영역의 시작점과 공통 조작 요소를 맞췄다.

## 재현과 한계

```sh
swift build --package-path setup/LazyestSetup -j 2
setup/LazyestSetup/.build/debug/LazyestSetup --export-preview /tmp/setup.png --preview-route guided-text --preview-width 720 --preview-language ko
```

`--preview-route` 값은 `install`, `text`, `desktop`, `dock`, `flow`, `guided-homebrew`, `guided-desktop`, `guided-dock`, `guided-text`, `guided-finished`다. `ko`와 `en`을 지원한다. 예제 렌더링은 새로고침, 의존성 조회, 설정 변경, 앱 실행을 시작하지 않는다. 이미지와 같은 이름의 JSON에 좌표가 저장된다.

Swift 빌드와 `git diff --check`가 통과했고, 렌더 로그에 Auto Layout 제약 경고는 없었다. 실제 앱에서 클릭/키보드/VoiceOver/다크 모드, macOS 권한 대화상자, 시스템 설정 적용, 설치/제거/로그아웃은 이번 정렬 점검에서 실행하지 않았다. 스크롤 아래 행은 공통 구현의 소스 확인 범위다.
